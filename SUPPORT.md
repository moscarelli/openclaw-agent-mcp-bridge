# Support

This project is an Experimental Community Preview maintained on a best-effort
basis. It does not include commercial support or guaranteed response times.

## Where to ask

- Use an issue for usage questions and reproducible bugs.
- Use the feature request form for proposed behavior changes.
- Follow `SECURITY.md` for vulnerabilities or suspected credential exposure;
  do not disclose those details in a public issue.

Before opening a request, check the README, existing issues, and documented
compatibility requirements. Include the bridge version or commit, Node.js and
OpenClaw versions, operating system, minimal reproduction steps, and sanitized
error output. Never include tokens, session keys, transcripts, local paths, or
other personal data.

The maintainer may close requests that cannot be reproduced, are outside the
project scope, or would weaken the documented security boundary.
