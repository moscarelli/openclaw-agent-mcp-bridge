# Contributing

This project is in a private validation phase.

- Open an issue before adding a provider, transport, or mutating tool.
- Keep changes narrowly scoped and covered by tests.
- Do not add real transcripts, credentials, personal paths, machine names, account IDs, or copied production configuration.
- Use synthetic fixtures only.
- Every pull request must pass tests, dependency review, secret scanning, and human review.
- Do not describe the project as official or stable.
